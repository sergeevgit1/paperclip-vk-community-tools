# VK Plugin UI Design System

Стилистические правила оформления интерфейсных компонентов VK Community Tools (Studio Dark).

## Основные правила

1. **Цветовая схема:**
   - Фон: `#1b1b1b` (глубокий тёмный);
   - Карточки: `#1b1b1b` с границей `border-white/10`;
   - Внутренние плашки метрик: `bg-white/[0.03]` с границей `border-white/5`;
   - Текст: основной `text-white/90`, приглушённый `text-white/45`, подписи `text-white/35`;
   - Акцент VK: `bg-blue-600/20` и `text-blue-400`.

2. **Скругления и тени:**
   - Панели настроек: `rounded-[2rem]`;
   - Карточки виджета: `rounded-2xl`;
   - Метрики и кнопки: `rounded-xl`;
   - Тени: мягкие тёмные `shadow-black/30`.

3. **Типографика:**
   - Заголовки с отрицательным трекингом: `tracking-[-0.04em]` и `text-balance`;
   - Метрики: крупные цифры `text-lg font-bold tracking-tight`.

4. **Композиция:**
   - Плоская иерархия без лишних декоративных вложенных контейнеров;
   - Виджет дашборда адаптируется под компактную колонку обзора компании;
   - Страница настроек выводит статус соединения, проверку и подсказку по привязке секретов.
